# Gallon Filler test: copy-and-paste list

The short list Joe asked for on 10/11/2026, ready to copy into an email or a quote request. Prices are typical list prices, not quotes. The fuller notes are in [Gallon-Filler-Test-Parts.md](Gallon-Filler-Test-Parts.md).

```
GALLON FILLER TEST - PARTS LIST

OPTION 1: UPC ONLY (counts + product)  -- my pick for the test
[ ] Fixed-mount barcode reader: Zebra FS10, Datalogic Matrix 120, or Cognex DataMan 150 ... $700-1,500
[ ] Clear splash shield (polycarbonate box with window) ... $50-100
[ ] Mounting bracket (80/20 aluminum or reader's bracket) ... $60-120
[ ] 24 V DIN-rail power supply + cable ... $40-80
[ ] Line PC: Raspberry Pi 5 kit or used mini PC ... $120-250
[ ] Network cable or Wi-Fi at the gallon filler (ask IT) ... $0-50
TOTAL: about $1,000-2,100

OPTION 2: UPC + CODE DATE (camera)
[ ] Entry smart camera with barcode + OCR: Hikrobot SC2000/SC3000, Datalogic Smart-VS, or Cognex In-Sight 2800 ... $1,500-5,000
[ ] Lens + LED light (same supplier) ... $200-600
[ ] Splash housing + mount ... $150-400
[ ] Photo-eye to trigger each jug: Banner, SICK, or Omron ... $60-150
[ ] 24 V power supply + cable ... $40-80
[ ] Line PC: mini PC ... $150-400
[ ] Network cable or Wi-Fi at the gallon filler (ask IT)
TOTAL: about $2,100-6,600

NOT NEEDED FOR THE TEST
- Tablet and TV: any PC or TV near the line with a web browser works.

WHO TO ASK FOR QUOTES
- Cognex, Keyence, Omron, Datalogic, or Zebra local rep (most will look at the line for free and many lend a demo unit)
- Your usual industrial supplier (Grainger, Motion, Allied, or AutomationDirect)

WHAT TO TELL THEM
"Test unit for a gallon milk line, about 75 jugs a minute, wet area.
Read the UPC on each jug to count and identify the product.
(Option 2: also read the printed code date and check it.)
It needs to send each read over the network as plain text to our own PC.
Can you demo or lend a unit?"

BEFORE ORDERING, CHECK ON THE LINE
- Which way the jugs face when they pass
- Where the date is printed (label, cap, or neck)
- A network jack or Wi-Fi near the gallon filler
```
