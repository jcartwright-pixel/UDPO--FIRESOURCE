MOCREO & Sensors

1. MOCREO key -

Paste the key here only, never in a chat or email. Once saved it is locked away and never shown again; only its last 4 characters show. A box left blank keeps what is saved.

2. Test connection

Reads the sensor list from MOCREO with the saved key. When it passes, the cooler readings start every 5 minutes; until then Cooler Temperatures is entered by hand.

3. Thermometers

Each box saves as you leave it. A sensor picked here is that cooler's MOCREO sensor; "Manual only" means the cooler is read by hand. Off leaves it off Cooler Temperatures; Remove (press twice) takes it off the list.
