2. Test connection

Reads the product list from RedZone with what is saved. Nothing is ever changed in RedZone. When it passes, Products gets a Get from RedZone button.

3. Where these come from

  1. Your everyday RedZone user name and password do not go here. RedZone's API uses its own token (or a client ID and secret).
  2. In RedZone, open the Developer Hub (or Site Admin Settings) and look for API access, API clients or tokens. If you can create one, make a read-only one for "UD Operations app".
  3. Copy the API address, and the token (or the client ID, secret and token address), into box 1 and press Save. The Developer Hub also shows the products address if it is not /products.
  4. Press Test Connection. Green means it works; red says what to fix. If there is no way to make a token, ask your RedZone rep for "API access for our account".
