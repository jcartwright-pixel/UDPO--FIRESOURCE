Paste an order or a whole route

Start each line with the product ID. A line with nothing after the name counts as one unit, so a list with one line per jug or carton adds up on its own. To give a count, put it after the ID or at the end, like 205 10 or 205 UD HVD Gallon x10. For full cases, add cs, like 205 6cs (6 cases is 24 gallons). When pasting a whole route, any line that doesn't start with a product ID starts the next order.
